# 아트 스타일 가이드 (M3 확정)

## 원칙

- **자체 제작 절차 생성 도트** — 외부 에셋 없이 코드로 생성(`src/systems/textures.ts`).
  라이선스 관리가 단순하고(전부 자체작), 팔레트 통일이 코드로 강제된다.
- 픽셀아트 규칙: **다크 아웃라인 + 3단 셰이딩**(외곽 어두운 색 → 중간 → 하이라이트), 2px 논리 그리드(맵 1px → 화면 2px), 이펙트는 캔버스 그라디언트 프리렌더 + ADD 블렌드.
- 폰트: **Galmuri11/9** (OFL-1.1) — 모든 UI 텍스트. 9px 이하 Galmuri9, 그 외 Galmuri11 Bold.

## 논리 규격

- 해상도 360×640 (9:16 세로), Scale.FIT 레터박스
- 스프라이트 계층: 소형 적 20~~24px · 중형 적 24~~28px · 플레이어 32×36 · 보스 54~66px
- 히트박스는 스프라이트보다 관대하게 작게 (데이터 `hitbox` 기준, 스프라이트와 분리)

## 규칙

- 적은 **아래를 향하는 실루엣**(피아 식별), 플레이어 계열은 위를 향한다.
- 배경 별 알파 ≤0.72·2px 고정 — 어떤 투사체보다 어둡고 작게(혼동 방지).
- 새 적 스프라이트는 신규 맵 또는 **팔레트 스왑 변형**으로 제작하고 이 문서의 테마 팔레트를 따른다.
