# 에셋 라이선스 대장

모든 외부 에셋은 이 파일에 기록한다. **이 대장이 완비되지 않으면 스토어 제출 불가로 간주한다** (PLAN.md 2장).

| 에셋                          | 출처                                    | 라이선스 | 사용 위치                     | 비고                           |
| ----------------------------- | --------------------------------------- | -------- | ----------------------------- | ------------------------------ |
| Galmuri 픽셀 폰트 (11/9/Bold) | https://github.com/quiple/galmuri (npm) | OFL-1.1  | public/fonts/, 전체 UI 텍스트 | 한글 픽셀 폰트, 표기 의무 없음 |
| 자체 절차 생성 스프라이트     | src/systems/textures.ts                 | 자체작   | 전 씬                         | M3에서 정식 아트로 교체 예정   |

원칙: CC0 우선(Kenney 등, 표기 의무 없음). 신규 제작분은 자체 저작. Tyrian CC-BY 에셋은 사용하지 않는다.
