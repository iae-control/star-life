# 별의 일생 — 외주 아트 스펙 (AI 이미지 생성용)

ChatGPT 등 AI로 그림을 받을 때 이 표준을 따른다. **받은 원본은 그대로 저장소에 넣지 않는다** —
Claude가 축소·배경 키잉·팔레트 정리·시트 조립을 거쳐 `public/assets/`에 통합한다.

## 공통 표준 (모든 스프라이트)

| 항목 | 값 | 이유 |
|---|---|---|
| 파일 형식 | PNG (JPG 금지) | 투명/키잉·무손실 |
| 생성 크기 | 1024×1024, **한 파일당 피사체 1개** | AI가 작은 픽셀 수치를 못 지킴 — 크게 받아서 우리가 축소 |
| 배경 | **투명** (가능하면) 또는 **단색 진남색 `#0A0A14`** | 체커보드 무늬가 "그려진" PNG는 못 씀. 흰 배경도 피할 것(가장자리 흰 태두리 발생) |
| 구도 | 피사체 중앙, 가장자리 여백 ~10%, 잘림 없음 | 축소·크롭 자동화 |
| 그림자 | 바닥 그림자·드롭섀도 금지 | 우주 배경이라 어색 + 키잉 방해 |
| 스타일 | 도트(픽셀아트) 느낌, 플랫 셰이딩 2~3단계, 진한 외곽선 | 기존 ansimuz/Galmuri 픽셀 톤과 통일 |
| 라이팅 | 위쪽 광원 고정, 화면 효과(글로우·렌즈플레어) 금지 | 글로우는 게임 엔진이 입힘 |
| 시점 | 수직 슈팅 탑뷰: 아군은 **위를 향함**, 적은 **아래를 향함** | 회전 없이 바로 사용 |

## 색 조합 (팔레트)

게임 배경이 아주 어두운 남색(`#05060F`~`#1A1030`)이므로:
- 스프라이트는 **채도 높고 밝게**, 큰 면적의 검정/암청색 금지 (배경에 묻힘)
- 외곽선은 순수 검정 대신 진한 남색 `#1A2030` 권장
- 진영별 주조색 — 아군기: 붉은/흰 계열(기존 기체와 통일), 성운 적: 청록, 원시별 적: 주황,
  주계열성 적: 골드, 적색거성 적: 진홍, 초신성 적: 백금/노랑, 블랙홀 적: 보라
- 한 스프라이트당 색 6~10개 이내 (도트 감성 유지)

## 애니메이션

AI는 프레임 간 일관성이 약하므로 **정지 1포즈만** 요청한다.
엔진 프레임(뱅킹 기울기, 엔진 화염 깜빡임, 2프레임 아이들)은 Claude가 코드/후처리로 만든다.
꼭 프레임이 필요한 것(폭발 등)은 "같은 그림의 4~6단계 변화를 가로로 나열한 한 장"으로 요청하되 결과물 검수 필요.

## 자산 목록 (우선순위순)

| # | 자산 | 게임 내 크기(px) | 요청 프롬프트 힌트 |
|---|---|---|---|
| 1 | 보스 7종: 아메바·프로토코어·헬리오스·크림슨·노바·싱귤래리티·**살인달팽이** | 96~140 | "거대 보스, 화면 아래를 향한 정면 탑뷰" — 달팽이는 눈자루 2개가 왼쪽 위로 뻗음 |
| 2 | 플레이어기 1종 (팔레트 변형 4종은 Claude가 처리) | 32×48 | "위를 향한 우주 전투기, 엔진 화염 포함" |
| 3 | 적기 소/중/대 3~6종 (테마 틴트는 Claude가 처리) | 30~60 | "아래를 향한 외계 전투기/생물" |
| 4 | 스테이지 배경 6종: 성운·원시별·주계열성·적색거성·초신성·블랙홀 안쪽 | 720×1280 세로 | "**세로로 이어붙여도 티 안 나는(seamless vertical tile)** 어두운 우주, 저대비" — 게임플레이 가독성 위해 밝은 요소 금지 |
| 5 | 시그니처: 배드민턴 라켓, 앵무새, 뼈다귀, 초록 산(어린지우 배경) | 다양 | 푸들 하무는 실사 유지 (교체 금지) |
| 6 | 프롭: 소행성·수정·잔해 / 오브 P·R·W·S | 30~90 / 16 | 오브는 글자 없이 색만 — 글자는 엔진이 얹음 |

## ChatGPT에 붙여넣을 프롬프트 템플릿

```
2D 세로 스크롤 슈팅게임(레트로 픽셀아트 스타일)용 스프라이트를 그려줘.

- 1024x1024, 배경은 투명(안 되면 단색 #0A0A14), 피사체 하나만 중앙에, 가장자리 여백 10%
- 도트 게임 스타일: 플랫 셰이딩 2~3단계, 진한 남색 외곽선, 색 8개 이내, 안티앨리어싱 최소
- 광원은 위쪽. 그림자·글로우·렌즈플레어·바닥 그림자 없음
- [아군이면] 위를 향한 정면 탑뷰 / [적이면] 아래를 향한 정면 탑뷰
- 그릴 것: (예) "곱슬 털 질감의 보라색 외계 달팽이 대왕. 껍데기는 소용돌이 무늬,
  왼쪽 위로 뻗은 눈자루 2개, 사악한 표정. 거대 보스 느낌"
```

## 전달 방법

받은 PNG를 그대로 Claude에게 업로드 (여러 장이면 zip도 가능).
파일명은 내용을 알 수 있게: `boss-snail.png`, `bg-nebula.png` 식으로.
이후 축소(니어리스트+팔레트 정리)·키잉·시트 조립·게임 통합·라이선스 대장 기록은 Claude가 수행.
